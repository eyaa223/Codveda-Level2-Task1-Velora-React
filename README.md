
# VELORA — React Single Page Application

A premium, responsive fashion website built as part of the
Codveda Technologies Front-End Development Internship.

## Project Overview

VELORA is a fictional contemporary fashion brand.
This project demonstrates a modern Single Page Application
built with React, Vite, and React Router.

## Features

- Responsive Home, About, and Contact pages
- Client-side navigation with React Router
- Mobile hamburger navigation
- Active navigation links
- Interactive Contact form
- Form validation using React useState
- Scroll reveal animations
- Scroll-to-top functionality
- Reusable Navbar and Footer components
- Responsive layouts for desktop, tablet, and mobile
- Custom 404 page

## Technologies

- React
- Vite
- JavaScript (ES6+)
- JSX
- React Router
- HTML5
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
